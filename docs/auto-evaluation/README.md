# Rapports d'auto-évaluation

Un rapport par thème, en trois parties : **Problèmes** (ce qui n'allait pas),
**Apprendre** (ce qu'on veut faire acquérir) et **Observer** (comment on le
vérifie).

La règle est que la partie « Observer » ne se remplit pas à la main : chaque
critère doit correspondre à un test qui échoue si le critère n'est plus tenu.
Un rapport dont les tests sont verts n'est pas une opinion sur la qualité du
thème, c'est une mesure — et un rapport sans test correspondant est un vœu.
